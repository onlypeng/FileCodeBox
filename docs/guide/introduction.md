# 介绍

FileCodeBox（驿码）是一个 **FastAPI + Vue3** 的匿名口令分享工具：不用注册，输入提取码就能取件，
像去驿站取快递一样。除基础的文本/文件分享外，还内置收件箱收集、跨设备聊天、WebRTC 直连传文件。

## 功能一览

| 能力 | 说明 |
|---|---|
| 提取码分享 | 单文件 / 多文件 / 纯文本；有效期按时长、取件次数或永久 |
| 二次口令 | 提取码之外再加一道口令，走另一条信道告知；只存哈希，猜错不扣次数 |
| 收件箱 | 投件码收、取件码取、管理码管；提交者只能上传，看不到别人的文件 |
| 直连快传 | WebRTC P2P 优先，服务器中转兜底且不落盘；房间缓存让后进来的人也能取 |
| 断点续传 | 分片上传 + Range 下载，中断后接着传 |
| 秒传去重 | 服务端落盘时流式计算哈希，同内容只存一份 |
| 多存储后端 | 本地 / S3 兼容 / OneDrive / WebDAV / OpenDAL，后台切换 |
| 管理后台 | 仪表盘、文件与房间管理、在线配置热生效、审计日志、TURN 连通性自检 |
| 安全 | PBKDF2 口令、JWT、IP 限流、敏感配置加密、强制首登改密、病毒扫描钩子 |
| 界面 | 中文简/繁/英、深浅色主题、移动端适配 |

## 适用场景

- 给同事传一个大文件，不想登录网盘
- 收集作业/材料，只想让对方上传、不让他看到别人的
- 两台设备之间直传，希望数据不经过服务器落盘
- 内网/小团队自建一个轻量分享服务

## 快速开始

```bash
docker run -d --restart always -p 12345:12345 \
  -v /opt/FileCodeBox:/app/data --name filecodebox \
  onlypeng/filecodebox:latest
```

打开 `http://<服务器IP>:12345`，管理后台在 `/#/admin`，默认口令 `FileCodeBox2023`（首次登录强制修改）。
手动部署、环境变量与反向代理见[快速开始](/guide/getting-started)。
